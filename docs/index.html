Unofficial iOS client

TVer Client

AltStore・SideStore・LiveContainerから最新版のUnsigned IPAを追加できる配布ソースです。

AltStore / SideStoreに追加LiveContainerに追加最新版IPAを直接取得
https://nmt3325.github.io/TVerClient/apps.json
自動更新ソース

使い方

  • 利用するアプリのボタンを押してソースを登録します。
  • 直接追加できない場合は、上のURLをSourcesへ貼り付けます。
  • LiveContainerではSources画面からTVer Clientを選びます。

署名とプライバシー

配布物は署名なしです。診断ログはトークン、Cookie、URLクエリ、実際の配信URLを除去してから書き出します。

注意事項

本プロジェクトは非公式で、TVerおよび各放送局とは関係ありません。視聴地域、配信条件、権利者の利用条件を守って利用してください。
